# Catherini Rebelo

[← Voltar ao portfólio](../README.md)

**Categoria:** landing page profissional  
**Atuação:** desenvolvimento da página e das interações  
**Tecnologias:** HTML, CSS e JavaScript  
**Versão dos arquivos analisados:** V15

## Problema

Apresentar a atuação de uma Terapeuta Sistêmica e Analista Comportamental com comunicação dirigida a mulheres e caminhos claros para conhecer o trabalho e entrar em contato.

## Solução

Uma página com apresentação profissional, seções de conteúdo, identidade visual própria e chamadas para os canais externos configurados no site.

## Recursos do projeto

- Seção inicial com apresentação e imagem.
- Conteúdo sobre a atuação profissional e padrões de comportamento.
- Seções de apresentação e contato.
- Encaminhamento para formulário e comunidade.
- Recursos de áudio com controles.
- Identidade visual com logotipo, imagens e ícones.
- Layout responsivo.

## Decisões técnicas

| Tecnologia | Aplicação |
| --- | --- |
| HTML | Conteúdo e estrutura da página |
| CSS | Tipografia, cores e adaptação às telas |
| JavaScript | Interações e controle de áudio |
| Serviços externos | Encaminhamento aos canais configurados |

## Desafios

Equilibrar conteúdo e hierarquia visual, revisar a aplicação da marca e permitir que a visitante controle a reprodução de áudio.

## Disponibilidade

O código é mantido em repositório privado. Esta apresentação documenta a versão local analisada; a publicação e os destinos externos devem ser conferidos no ambiente do projeto.
